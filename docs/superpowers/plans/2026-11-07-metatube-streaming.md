# MetaTube 1.2.1：逐目录扫描与处理

用户确认的目标：完整读取当前目录，按首次出现的番号分组，完成元数据、本地文件和网盘整理后再读取下一目录。保留现有队列、深度和接口返回顺序。

## 实现与验收

- 将全库汇总转换为目录批次生成器；当前目录分页完成前不得修改目录内容。
- 配置父根 `/jav` 统一归档至 `/jav/{前缀}/{番号}`；平铺来源与已有分类目录增量合并，保持版本编号、STRM 链接及登记文件。
- 按文件 ID 去重，保留已处理视频作为新字幕的关联依据；按文件 ID 和配置范围核验断点续跑，不依赖全库扫描集合。
- 元数据和图片每番号每轮复用；上限按不同番号的成功、未找到、失败计数，跳过不计数，达到后停止发现新目录。每番号只统计一次，状态优先级为失败、未找到、成功、跳过。
- 真正独立父根出现同番号时拒绝后来批次跨根合并，保留此前结果。
- 补充 INFO 阶段日志，V2/V3 同步升至 1.2.1，更新说明，不新增配置、API、依赖或数据库结构。
- 测试首部输出先于下一目录读取、上限、平铺与分类合并、多版本、CD/字幕、分页、移动去重、重叠根、断点续跑及现有保护。
- 验证命令：`PYTHONDONTWRITEBYTECODE=1 .superpowers/venv-meta/bin/python -m unittest discover -s tests -p 'test_metatube*.py'`。改动前基线 108 项通过。

真实 NAS 验收使用单部影片；本地实现和离线回归不操作在线网盘或媒体库。
