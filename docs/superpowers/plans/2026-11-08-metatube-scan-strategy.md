# MetaTube 1.2.1：全量／增量扫描

用户批准：115 直连增加 scan_strategy（full/incremental，默认 full），旧 scan_mode 改显示标签为“扫描范围”。两种模式均逐目录立即处理并遵守上限。

- 增量在现有 SQLite 中保存根 ID 绑定、目录队列、已访问目录、当前目录剩余影片与文件 ID、本轮处理 ID 和番号归档根；先保存完整目录快照，再处理，每片结束事务推进。
- 恢复使用 ID 和配置范围核验，不依赖旧路径、页码或偏移。中途崩溃重放未提交批次，沿用已有文件操作幂等性。
- 一轮完整结束后，下次任务从头开启新轮次；单次任务不自动绕回。单片普通失败／未找到推进，下一轮重试。
- Cookie／风控／停止保留当前未完成影片。目录读取、分页、快照或进度保存失败停止并保留队首。
- 账户、根与顺序、范围／深度、输出根、整理和番号识别选项变化使进度失效；调度、上限、请求间隔和同账户 Cookie 变化保留位置。
- 执行全量清除增量检查点，但保留媒体登记；页面／日志显示模式、恢复位置、暂停原因和周期完成状态。
- V2/V3 同步并入未发布的 1.2.1；无新增外部 HTTP 路由。

验收：100 片/上限30跨重启为30/30/30/10；目录中途、移动与重叠去重、跨任务独立根保护、CD/字幕、多版本、循环发现新增、失败／停止／崩溃／分页与提交失败、损坏重置、配置失效和全量重置。Python 3.12 MetaTube、Python 3.14 全仓回归。
