# MetaTube 1.4.0：厂商归并与独立网盘目标

用户批准的行为：旧配置保持前缀布局，新增厂商归并（6 组＋其他／未知，可编辑精确别名）；archive_loose 开启时可选单个 archive_root，留空跟随各扫描归档根，明确统一目标允许多源合并。

## 执行任务

1. 分类策略：NFKC、casefold、空白规范化，maker 优先、空时 label；安全单目录名称，校验重复别名／分组。
2. 迁移：先持久化意图再移动，按文件／版本记录来源，保护改动和未归属文件，保留版本及播放标识；登记库任务支持源已空后的重分类／重定向，未完成操作可重规划。
3. 云端与扫描：独立目标 ID，排除嵌套目标子树；旧／新类别同等识别；来源和目标分离授权；不移动扫描根，不自我嵌套；规则和目标改变使扫描游标失效。
4. 清理：仅本次迁空的旧影片／分类目录；本地 rmdir，云端 ID／父子关系／两次空校验后移入回收站，不清空回收站，保护所有扫描根及目标根。云端清理须没有其他写入任务。
5. 表单：library_layout(prefix/maker)、maker_groups(每行目录=别名列表)、archive_root(留空跟随＋独立单选)、cleanup_empty_dirs(默认开启)；V2/V3 1.4.0、文档和完整回归。

## 验证

别名／未知、前缀迁移、稳定 token、多版本／分段／字幕、冲突保护、移动后提交前中断、目标同根／嵌套／外部、多源统一、源为空时重定向、规则／账户／来源变化、旧空目录保护及响应丢失、目录已删除跳过、表单取消不改扫描范围。Python 3.12 MetaTube、Python 3.14 全仓回归及独立审查。
